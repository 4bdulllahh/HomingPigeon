HomingPigeon {version} - Safe, simple email for your business
================================================================

HOW TO INSTALL (Windows 10 and 11)

  1. Right-click the downloaded .zip file and choose  Extract All... , then  Extract
  2. In the folder that opens, double-click  "HomingPigeon Setup.exe"
  3. Click  Install
  4. When it's finished, choose where you'd like shortcuts and click  Finish

That's it. Setup downloads what the app needs (about 80 MB) and shows you
every step while it works. It takes about 2-5 minutes and needs an internet
connection. No administrator password is needed.

Keep the extracted folder together while you install. Setup.exe uses the
"runtime" and "files" folders sitting next to it, so please don't drag it out
on its own. Once the app is installed you can delete the whole folder.


"WINDOWS PROTECTED YOUR PC"?

Windows shows this for new programs it hasn't seen many times before.
Click  More info , then  Run anyway .


"SMART APP CONTROL BLOCKED AN APP THAT MAY BE UNSAFE"?

Some Windows 11 computers block new programs completely. No problem:
close the message and use the backup installer instead.

    1. Right-click  Install HomingPigeon (if Setup is blocked).bat
    2. Choose  Properties
    3. At the bottom of the first tab, tick  Unblock , then click  OK
    4. Double-click the .bat file

Step 3 is the important one. Without it Windows blocks the .bat too, and says
"files of this type from the internet can be dangerous". Ticking Unblock tells
Windows you fetched this file on purpose. It changes nothing else on your PC.

The backup installer downloads Python from python.org using Windows' own
tools, checks the download is genuine, and then opens exactly the same Setup
window. Leave the "files" folder next to it - it needs it.

Shortcut: tick Unblock on the downloaded .zip file itself, the same way,
BEFORE you extract it. Then nothing inside needs unblocking one by one.


UPDATING

Download the newest release and run its Setup the same way. Your contacts,
templates and settings are kept.


REMOVING

Settings > Apps > Installed apps > HomingPigeon > Uninstall.


MAC OR LINUX?

This Setup is for Windows. On the Releases page, download "Source code (zip)",
unzip it, and double-click the "Start HomingPigeon" file for your computer.
